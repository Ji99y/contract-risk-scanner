Why it matters
Built for agents, not humans
Every DeFi agent needs a security gate. This is it.
🛡
30 checks in one call
19 token-level checks (honeypot, tax, mintability, ownership) + 11 address-level checks (phishing, blacklist, cybercrime) run in parallel.
⚡
Batch scan up to 10
Scan multiple addresses simultaneously with concurrency control. Get a summary with total / safe / caution / blocked counts and scan duration.
🔑
No API key required
Uses GoPlus Security's public API tier. Zero setup for any agent to start calling this Skill immediately on any of 13 supported EVM chains.
✅
CertiK Skill Scanner ready
No shell execution, no filesystem access, minimal network scope (GoPlus API only), no hardcoded secrets. Designed to pass CertiK review from day one.
🧩
Composable by design
Any Pharos agent can import run() or runBatch() in one line. The Skill is the gate — agents decide what to do with the verdict.
📊
Structured output
Returns a typed JSON report: risk score (0–100), risk level, recommendation, flag list sorted critical-first, and full token metadata.

Installation

git clone https://github.com/Ji99y/contract-risk-scanner
cd contract-risk-scanner
npm install

Quick start

import { run, runBatch } from "./src/index";

// Single scan
const result = await run({
  address: "0x6b175474e89094c44da98b954eedeac495271d0f",
  chainId: 1,
  checkType: "both"
});

if (result.recommendation === "BLOCK") {
  throw new Error("Blocked: " + result.flags[0].message);
}

Single scan — run(input)

Input parameters

Field Type Description
address required string EVM address to scan (0x…)
chainId required string | number EVM chain ID (1 = Ethereum, 56 = BNB Chain, etc.)
checkType optional "token" | "address" | "both" Which checks to run. Defaults to "both"

Output

Field Type Description
riskScore number 0 (safe) to 100 (critical risk)
riskLevel string SAFE / LOW / MEDIUM / HIGH / CRITICAL / UNKNOWN
recommendation string PROCEED / CAUTION / BLOCK
flags RiskFlag[] Detected risk flags, sorted critical-first
details object Token metadata (name, symbol, tax rates, holders) and API notes

Batch scan — runBatch(input)

const batch = await runBatch({
  addresses: [
    { address: "0x...", chainId: 1 },
    { address: "0x...", chainId: 56, checkType: "token" },
  ],
  concurrency: 3  // max parallel requests, default 3
});

// batch.summary
// { total: 2, safe: 1, caution: 0, blocked: 1,
//   highestRisk: "CRITICAL", scanDurationMs: 1240 }
